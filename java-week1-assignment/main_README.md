# Java Development Internship - Week 1 Assignment

**Organization:** WeIntern Pvt Ltd
**Objective:** Strengthen Java programming and OOP concepts.

## Overview
This repository contains the three Week 1 tasks:
1. Library Management System
2. Banking Application
3. Java Collections Challenge

Each task is in its own folder with its own source code and README file.

## Repository Structure
```
java-week1-assignment/
├── library_management_system/
│   ├── src/
│   └── README.md
├── banking_application/
│   ├── src/
│   └── README.md
├── java_collections_challenge/
│   ├── src/
│   └── README.md
├── screenshots/
└── main_README.md
```

## How to Run Each Task
Go into the task folder's `src` directory, then:
```
javac *.java
java Main
```

- Java program structure, compilation, and execution flow
- Variables, data types, operators, conditions, loops, and methods
- OOP: classes, objects, constructors, encapsulation
- Menu-driven console applications
- Collections: ArrayList, HashMap, Queue
- Exception handling
- Clean project organization and documentation
